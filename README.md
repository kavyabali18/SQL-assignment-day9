# Intergration of SQL with Pandas

## Overview

This project demonstrates how to connect a MySQL database with Python using Pandas. Student data is stored in a MySQL database and accessed through Python for data retrieval and analysis.

## Database Information

* Database Name: `college_db`
* Table Name: `students`

## Student Records

The database contains student details including:

* Student ID
* Student Name
* Department
* CGPA

## Features

* Create a MySQL database
* Create a student table
* Insert student records
* Retrieve data using SQL queries
* Connect MySQL with Python
* Load database records into a Pandas DataFrame
* Display student information

## Technologies Used

* Python
* Pandas
* MySQL
* MySQL Connector

## Project Files

### college_db.sql

Contains:

* Database creation
* Table creation
* Data insertion
* SQL queries

### college_pandas.py

Contains:

* MySQL database connection
* Data retrieval using Pandas
* Display of student records

## Output

The program retrieves student records from MySQL and displays them in a Pandas DataFrame.

## Learning Outcome

This project helps understand the integration of SQL databases with Pandas and demonstrates how data stored in MySQL can be accessed and processed using Python.
